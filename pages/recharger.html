Instructions de recharge

  1. 1. Le dépôt minimum est de 3 500 FCFA. Les dépôts inférieurs à ce montant ne seront pas crédités sur votre compte.
  2. 2. Veuillez utiliser votre compte le plus récent pour chaque dépôt.
  3. 3. Le montant de la marge doit correspondre au montant du paiement.
  4. 4. Si votre dépôt n'est pas crédité immédiatement après le transfert, veuillez contacter le service client.
  5. 5. Cher membre, si vous recevez le message « Portefeuille indisponible » lors d'un rechargement via Moov, vous pouvez utiliser Togocel pour recharger votre compte ; le rechargement se déroulera normalement.

Information importante : aucun prestataire de paiement n'est actuellement connecté. Les instructions ci-dessus sont des références non activées ; ne transférez pas de fonds. Aucune recharge ne peut être confirmée.
