# Payment logo sources

Locally hosted official operator artwork, visually checked before use:

- Orange: https://www.orange.bf/particuliers/resources/img/master-logo.svg
- Telecel Faso: https://www.telecelfaso.bf/wp-content/uploads/2022/08/logo-200x60-1.png
- Wave: https://www.wave.com/img/nav-logo.png
- Mixx by Yas (formerly TMoney): https://www.yas.tg/wp-content/uploads/2025/07/mixx-logo.svg

SVG sources were rasterised to PNG for the existing safe image allowlist.
The displayed payment-channel name and identifier still come from the server;
the Mixx logo does not rename or change existing TMoney payment requests.
Configured administrator artwork takes precedence over the bundled defaults.
MTN and Moov use the existing local assets.
